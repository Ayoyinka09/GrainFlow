# GrainFlow

GrainFlow coordinates the movement of goods from supplier → warehouse → factory (cleaning and bagging) → warehouse → millers, with full account of production losses.

## Users
- Warehouse staff
- Factory team
- Logistics department

## Problem
Grain cleaners struggle to maintain accurate, real-time visibility of **inventory, warehouse activities, production receipts, and deliveries** when these processes are managed in silos. This leads to:
- Stock discrepancies
- Delayed order fulfilment
- Poor coordination between factory and warehouse
- Inefficient delivery planning

## Main Journey
- Receive goods from the factory
- Record and track inventory in the warehouse
- Manage stock movements and orders
- Prepare goods for dispatch
- Coordinate deliveries

The system provides real-time visibility across warehouse, factory, and delivery processes so each team knows what has been produced, what is available in stock, what is being dispatched, and what has been delivered.
